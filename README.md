# 系统架构设计师（第二版）复习笔记

本仓库用于软考「系统架构设计师（第二版）」考试的备考与复习，包含考试大纲、教材和按章节整理的复习笔记。内容以覆盖大纲考点、帮助理解记忆和练习自测为目标。

## 资料入口

- `01.系统架构第二版-大纲.pdf`：考试大纲，复习时先对照本章考点。
- `02.系统架构设计师第二版-教材.pdf`：教材原文，笔记中的页码均指 PDF 文件页码，而非书页页码。
- `复习笔记/README.md`：复习总目录，包含 20 章入口、教材 PDF 起始页和复习进度。

教材上篇为第 1～11 章，下篇为第 12～20 章，分别对应 `复习笔记/上篇/` 和 `复习笔记/下篇/`。

## 复习笔记结构

每章一个目录，主要包含：

```text
第NN章-章名/
├── README.md          # 本章笔记，唯一文字数据源
├── figs/              # SVG 插图源文件
├── 实践案例/           # 可动手实践的案例
├── 扩展知识/           # 本章补充资料
├── 第NN章-章名.html    # 生成的单文件 HTML，可浏览器打开及打印
└── 第NN章-章名.docx    # 生成的 Word 文档
```

主笔记统一包含六个板块：大纲考点、知识点笔记、重点与易错点、练习与真题、疑问与查漏补缺、末尾参考答案。练习题与答案分开，便于先独立完成再核对。

## 复习方法

1. 从 `复习笔记/README.md` 选择章节，查看对应的大纲考点和教材页码。
2. 阅读主笔记，结合实例、表格和 SVG 示意图理解核心概念。
3. 完成本章练习题后，再集中核对末尾参考答案。
4. 按需要通过 `实践案例/` 和 `扩展知识/` 加深理解。
5. 完成一章后，更新总目录中的复习状态。

## 重新生成 HTML 和 DOCX

只修改章节目录下的 `README.md` 和 `figs/*.svg`，不要手工编辑生成产物。

在仓库根目录执行：

```bash
# 同时生成 HTML 和 DOCX
python tools/build_notes.py "复习笔记/上篇/第01章-绪论"

# 仅生成 HTML（纯标准库，无第三方依赖）
python tools/build_notes.py "复习笔记/上篇/第01章-绪论" --html-only

# 仅生成 DOCX
python tools/build_notes.py "复习笔记/上篇/第01章-绪论" --docx-only
```

生成 DOCX 需要安装 `python-docx`、`svglib`、`reportlab` 和 `pymupdf==1.26.7`，建议在虚拟环境中安装。微软雅黑字体默认从 `/mnt/c/Windows/Fonts/msyh.ttc` 和 `msyhbd.ttc` 探测，也可通过 `MSYH_FONT`、`MSYH_BOLD_FONT` 环境变量指定。

生成后应检查插图、中文字体、表格跨页表头和 Word 页码；生成器不会代替人工完成内容与打印效果校验。

## 维护约定

- 严格对照考试大纲整理笔记，重点、高频考点和易错点应明确标记。
- 重要教材配图使用 SVG 重绘，图文互相印证。
- 实践案例和扩展知识放在对应子目录，不并入主笔记的六个板块。
- HTML 与 DOCX 均由统一生成器产出，避免手工修改导致内容不一致。
- 更详细的撰写、绘图和排版规范见 `AGENTS.md`。
