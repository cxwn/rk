二、知识点笔记

2.1 计算机系统概述（2.1）

计算机系统（Computer System）是指用于数据管理的计算机硬件、软件及网络组成的系统：按人的要求接收和存储信息，自动进行数据处理和计算，并输出结果信息。通常所说的计算机系统指硬件子系统 + 软件子系统；把连接多个计算机以实现计算机间数据交换的网络设备称为计算机网络。

  • 硬件：由机械、电子元器件、磁介质和光介质等物理实体构成，包括处理器（含运算单元和控制单元）、存储器、输入设备和输出设备等，是有形的。
  • 软件：一系列按照特定顺序组织的数据和指令，控制硬件完成指定功能，是无形的。分为系统软件（支持应用软件运行、提供平台支撑，如操作系统、编译工具）和应用软件（为某一专门应用目的而开发，如办公、娱乐软件）。

从功能看，硬件与软件的界限正在逐渐模糊：某些功能既可由硬件实现也可由软件实现（典型如可编程逻辑，设计阶段可当软件对待，运行时以逻辑门物理形态存在）。计算机系统可从结构、性能、规模、用途等维度分类（通用计算机、嵌入式计算机、电信/家用/可穿戴设备等），同一设备可归属多个类别，分类没有严格界限。

2.2 计算机硬件（2.2）

1. 硬件组成与处理器 ⭐【重点】

冯·诺依曼结构把计算机硬件划分为运算器、控制器、存储器、输入设备、输出设备 5 部分；现实硬件中，控制单元和运算单元集成为处理器，输入/输出设备常集成为一体，因此按处理器、存储器、总线、接口和外部设备来阐述。

处理器（CPU）是运算和控制的核心：位宽从 4 位发展到 64 位；能力上集成多级缓存、多种总线和接口；内核从单核发展为多核、异构多核和众核。指令集按复杂程度分两类 ⭐【高频考点】：

指令集全称代表趋势
CISC 复杂指令集Complex Instruction Set ComputersIntel、AMD 的 x86 CPU因历史原因仍存在
RISC 精简指令集Reduced Instruction Set ComputersARM 和 Power几乎所有后期出现的指令集均为 RISC，是发展趋势

典型处理器体系结构中：指令部件通过 MMU-Cache 存储结构取得指令并译码控制；存取部件取数据；寄存器组为运算器准备数据与结果寄存器；运算部件（整型、浮点、向量）执行运算；完成部件对结果排队并向指令部件反馈，控制指令顺序执行、跳转等时序。各部件经地址总线、数据总线互连。

2. 存储器 ⭐【重点】

存储器按硬件结构可分为 SRAM、DRAM、NVRAM、Flash、EPROM、Disk 等。计算机系统通常采用分层体系（Memory Hierarchy），按与处理器的物理距离分 4 个层次 ⭐【高频考点】：

层次位置与介质典型容量特点
片上缓存处理器核心内，SRAM16kB～512kB（L1/L2）速度最快、容量最小
片外缓存处理器核心外，需经交换互联开关访问，一般也是 SRAM256kB～4MB（L2/L3 或平台 Cache）容量较片上略大
主存（内存）独立部件/芯片，DRAM，经总线连接数百 MB～数十 GB依赖不断充电维持数据（易失）
外存磁带、磁盘、光盘、各类 FlashNor Flash 为 MB 级，磁盘为 GB/TB 级速度慢、容量大、掉电保持数据

外存掉电保持数据但并非永久：Flash 约 10 年、光盘数年至数十年、磁盘 10 年以上、磁带 30 年以上。整体规律：越靠近处理器，速度越快、容量越小、单位成本越高。

3. 总线、接口与外部设备

总线（Bus）是计算机部件间遵循某一特定协议实现数据交换的形式。按所处位置分三类 ⭐：

类型别称作用范围
内总线片上总线、片内总线各类芯片内部互连
系统总线局部总线（广义次级联）计算机中 CPU、主存、I/O 接口之间
外部总线通信总线计算机板与外部设备之间、或计算机系统之间

总线之间通过桥（Bridge）连接，桥是一种特殊外设，主要实现总线协议间的转换。总线性能指标有总线带宽、服务质量 QoS、时延和抖动等。常见并行总线：PCI、PCIe、ATA(IDE)；常见串行总线：USB、SATA、CAN、RS-232、RS-485、RapidIO 和以太网等；专业领域还有航空 ARINC429/659/664、MIL-STD-1553B，工控 CAN、IEEE1394、VME 等。

接口是同一计算机不同功能层之间的通信规则：显示类（HDMI、DVI）、音频类（TRS、RCA、XLR）、网络类（RJ45、FC）、PS/2、USB、SATA、LPT 打印、RS-232 等；离散量接口与 A/D 转换接口多随需求设计。一种总线可对应多种接口（如以太网总线可用 RJ-45 或同轴电缆连接）。

外部设备（外围设备）是计算机的非必要设备：包括所有输入输出设备以及部分存储设备（外存），如键盘、鼠标、显示器、扫描仪、摄像头、麦克风、打印机、光驱、网卡、存储卡/盘；移动穿戴设备中有加速计、GPS、陀螺仪、感光和指纹识别设备等。外设都通过接口与计算机主体连接。

2.3 计算机软件（2.3）

1. 软件概述

计算机软件是指计算机系统中的程序及其文档，是计算任务的处理对象和处理规则的描述。处理对象是数据（数字、文字、图形等，只是表示而无含义）或信息（数据及有关的含义）；处理规则指处理的动作和步骤；文档是便于了解程序的阐述性资料。软件按作用和运行环境分为系统软件（不依赖特定应用领域的通用软件，可再分操作系统、程序设计语言翻译系统、数据库管理系统和网络软件）和应用软件（为某类应用需要设计，可再分专用与通用）。

2. 操作系统 ⭐【重点】

操作系统是计算机系统的资源管理者，首要作用是通过 CPU 管理、存储管理、设备管理和文件管理合理分配资源，是配置在计算机硬件上的第 1 层软件：向下管理裸机，向上为其他软件提供支持、为用户提供接口。

组成：内核（Kernel）+ 配套软件（GUI、常用应用程序、实用程序、开发运行构件）。内核提供进程管理（任务管理）、存储管理、文件管理和设备管理，对硬件抽象后向应用提供统一的系统调用接口（API）；内核常驻内存、以 CPU 最高优先级运行、可执行特权指令、可直接访问各种外设和全部主存空间。

三大作用：①管理运行程序、分配软硬件资源（处理器/存储/文件/I/O 设备管理）；②提供友善人机界面（GUI）；③为应用开发运行提供高效平台（呈现一台「虚拟计算机」，屏蔽物理设备细节）。

四个特征 ⭐【高频考点】：

特征含义关键点
并发性宏观上多个程序同时运行单 CPU 下微观上交替轮流执行；多 CPU 才可并行
共享性资源被多个并发进程共同使用而非独占共享方式分同时共享和互斥共享
虚拟性把一个物理实体变为多个逻辑对应物，或把多个物理实体变为一个逻辑对应物提供易用高效的操作环境（如虚拟内存）
不确定性进程「走走停停」，执行时机、速度、完成时间不可预知可能导致执行结果不唯一

操作系统分类 ⭐：

类型核心思想记忆要点
批处理操作系统单道：一次只有一个作业装入内存；多道：多个作业装入内存，I/O 时把 CPU 交给其他作业多道三特点：多道、宏观并行、微观串行；作业由用户程序、数据和作业说明书组成
分时操作系统CPU 时间划分为很短时间片，轮流为各终端用户服务四特点：多路性、独立性、交互性、及时性；用户感觉独占系统
实时操作系统以足够快的速度处理外来信息，在被控对象允许的时间范围内快速反应对交互要求不高、要求可靠性；分实时控制系统（火炮、自动驾驶）和实时信息处理系统（订票、检索）
网络操作系统使联网计算机方便有效地共享网络资源、为网络用户服务特征：硬件独立性、多用户支持、目录服务等
分布式操作系统为分散计算机组成的系统配置，统一界面、协同完成任务是网络操作系统的更高级形式，增加透明性、可靠性和高性能
微型计算机操作系统常用的微机 OSWindows、Mac OS、Linux
嵌入式操作系统运行在嵌入式智能设备中，统一协调软硬件资源五特点：微型化、可定制、实时性、可靠性、易移植性（HAL+BSP）；常见 VxWorks、μClinux、μC/OS、eCos 等

3. 数据库 ⭐【重点】

数据库（DB）是指长期存储在计算机内、有组织的、统一管理的相关数据的集合，不仅描述数据本身，还包括事物之间的联系，具有较小的冗余度、较高的数据独立性和易扩展性，可为多个用户共享。早期有层次式、网络式、关系型三种；目前最常见的是关系型和非关系型。按存储体系可分为 5 类：

类型存储特点通俗理解
关系型数据库把复杂数据结构归结为简单的二元关系（二维表），操作建立在关系表格上多张 Excel 表互相关联
键值（Key-Value）数据库数据存为键值对集合，键是唯一标识符大字典，按 key 取 value
列存储数据库相对行式存储，按列组织表中数据按列整列地读，利于分析统计
文档数据库存放 XML/JSON/BSON 等自描述、分层树状文档，文档相似但不必相同可视为其值可查的键值数据库
搜索引擎数据库面向搜索引擎爬取数据的特定格式存储为检索性能优化

关系数据库：数据模型是数据库系统的核心与基础，具有数据结构、数据操作和完整性约束条件三要素 ⭐。关系可理解为二维表，用若干关系表示实体及其联系；主码能唯一确定某个实体（如学号唯一确定学生）。例如：学生（学号，姓名，年龄，系别）、课程（课程号，课程名，学分）、选课（学号，课程号，分数）。

数据库设计特点：以数据模型为核心展开、静态结构设计与动态行为设计分离、试探性、反复性和多步性；设计方法分直观设计法、规范设计法、计算机辅助设计法和自动化设计法 4 类（常用 3NF 方法、E-R 方法等）。设计分 6 个阶段 ⭐【高频考点】：

阶段主要任务关键产物/方法
需求分析调查现行系统，明确数据需求和业务处理需求需求说明书
概念结构设计建立信息模型（数据建模），与具体 DBMS 无关E-R 方法：局部 E-R → 全局 E-R → 全局优化

运行维护转储和恢复、安全完整性控制、性能监督分析与改造、重组重构保证正常运行与优化

分布式数据库系统（DDBS）：针对地理上分散、管理上又需要不同程度集中的需求提出。满足分布性、逻辑相关性、场地透明性和场地自治性的称为完全分布式数据库系统；特点是数据的集中控制性、数据独立性、数据冗余可控性、场地自治性和存取的有效性。我国提出的 4 层结构模式 ⭐：

4. 文件系统 ⭐【重点】

文件（File）是具有符号名的、在逻辑上具有完整意义的一组相关信息项的集合，包括文件体（真实内容）和文件说明（文件名、类型、存储地址、长度、访问权限、时间等管理信息）。文件系统是操作系统中实现文件统一管理的一组软件和相关数据的集合，功能：按名存取（而非按地址存取）、统一用户接口、并发访问和控制、安全性控制、优化性能、差错恢复。常用文件系统类型有 FAT、VFAT、NTFS、Ext2、HPFS 等。

文件分类：按性质用途分系统文件、库文件、用户文件；按保存期限分临时、档案、永久文件；按保护方式分只读、读/写、可执行、不保护文件；UNIX 分为普通文件、目录文件和设备文件（特殊文件）。

逻辑结构（用户角度）分两类：有结构的记录式文件（由一个以上记录构成，记录可定长或不定长）和无结构的流式文件（一串顺序字符流/字节流，用读/写指针指出下一个要访问的字符，可看作记录式文件的特例）。

物理结构（存储设备上的存放方法）⭐【易错】：

物理结构存放方式存取特点
连续结构（顺序结构）逻辑上连续的信息依次放在连续编号的物理块上知道起始块号 + 长度即可方便存取
链接结构（串联结构）放在不连续物理块，每块设指针指向下一块知道第 1 个块号即可按链指针查找整个文件
索引结构放在不连续物理块，系统为每个文件建索引表（逻辑块号→物理块号），索引表起始地址放在文件目录项中通过索引表直接定位，索引表一般占一个或几个物理块（多物理块时可链接文件或多重索引）

存取方法：顺序存取（按顺序依次读/写）和随机存取（按任意次序读/写）。

5. 网络协议与中间件 ⭐【重点】

协议是网络中的计算机进行通信时，为实现数据正常发送与接收必须遵循的事先约定好的规则，规定通信的数据格式、传送时序以及控制信息和应答信号等。常用网络协议包括局域网协议（LAN）、广域网协议（WAN）、无线网协议和移动网协议；互联网使用 TCP/IP 协议簇。

中间件（Middleware）是应用软件与各种操作系统之间使用的标准化编程接口和协议，处在操作系统、网络和数据库之上、应用软件的下层，起承上启下作用，使应用开发独立于硬件和操作系统并能在不同系统上运行，属于可复用基础软件。

6. 软件构件

构件（组件）是一个自包容、可复用的程序集，整体向外提供统一访问接口，外部只能通过接口访问而不能直接操作内部。两个最重要特性：自包容与可重用 ⭐。

构件组装模型：需求分析定义功能后，设计构件组装结构（系统划分为构件集合、明确关系），再独立开发/重用/购买构件，最后组装、测试发布。开发过程：设计构件组装 → 建立构件库 → 构建应用软件 → 测试与发布。优点：自包容使扩展容易、重用降低成本、粒度小便于团队并行独立开发；缺点：依赖经验丰富的架构设计师、为重用可能牺牲性能、学习成本高、第三方构件库质量难以控制。

2.4 嵌入式系统及软件（2.4）⭐【重点】

1. 组成及特点

嵌入式系统（Embedded System）是为了特定应用而专门构建且将信息处理过程和物理过程紧密结合为一体的专用计算机系统；以应用为中心、以计算机技术为基础，软硬件可配置可裁减，需满足功能、可靠性、成本、体积和功耗的严格要求。嵌入式软件指可运行在嵌入式系统中的程序代码和帮助这些软件开发所用的工具或环境软件的总称。

基本工作原理：通过外部接口采集输入信息或人机接口输入的命令，对数据加工计算，将结果通过外部接口输出控制受控对象。组成 5 部分：

组成要点
嵌入式处理器抵抗高温、寒冷、电磁、加速度等恶劣环境，低功耗、体积小；工艺分民用、工业、军用三档
相关支撑硬件处理器以外的存储器、定时器、总线、I/O 接口及专用硬件（教材 ARM 实例：Flash/SDRAM/硬盘、LCD、键盘、RS-232/USB/JTAG、TCP/IP 与 CAN 总线）
嵌入式操作系统管理计算机资源和应用软件，应具备实时性、可剪裁性和安全性
支撑软件为应用开发运行提供公共服务与开发调试能力，通常以库的方式被引用
应用软件为完成嵌入式系统某一特定目标开发

特点 8 条：专用性强；技术融合；软硬一体、软件为主（有 IP 核）；比通用计算机资源少；程序代码固化在非易失存储器中；需专门开发工具和环境（本身不具备开发能力）；体积小、价格低、工艺先进、性能价格比高、配置要求低、实时性强；对安全性和可靠性要求高。

2. 分类

  • 按用途分嵌入式实时系统和嵌入式非实时系统，实时系统又分强实时（Hard Real-Time）和弱实时（Weak Real-Time）。实时系统是指能够在指定或确定的时间内完成系统功能并对外部或内部、同步或异步事件做出响应的系统：计算正确性不仅取决于逻辑正确性，也取决于结果产生的时间，时间约束不满足就是系统错误。
  • 按安全性要求分安全攸关（Safety-Critical/Life-Critical）系统和非安全攸关系统。安全攸关系统是指其不正确的功能或失效会导致人员伤亡、财产损失等严重后果的计算机系统。

4. 安全攸关软件的安全性设计（DO-178）⭐【高频考点】

IEEE 将安全攸关软件定义为「用于一个系统中，可能导致不可接受的风险的软件」。安全性属于系统特性，软件自身无所谓安全与否，但作为安全攸关系统的一部分时可能助长不安全因素；安全性分析应自上而下、结合场景。应按软件对安全性的影响程度分配开发保证级别：级别越高，要求的开发和验证活动、依赖性证据、错误识别排除越多，成本也越高，并非越高越好。

DO-178 是美国 FAA 民用飞机适航标准中针对机载软件的标准（《机载系统/设备合格审定中的软件考虑》），被航空、航天等安全攸关领域普遍采用。1982 年首版、1992 年 DO-178B 成为国际公认机载软件开发标准、2011 年 DO-178C 新增工具鉴定、基于模型的开发验证、面向对象技术和形式化验证。

DO-178B 的目的：为机载软件提供指导，使其在满足适航要求的安全性水平下完成预期功能。精髓是目标、过程、数据三要素 ⭐：

要素内容关键点
目标软件生命周期需达到的 66 个目标，按 A～E 安全等级分布选择该标准就必须满足其全部适用目标
过程为满足目标要进行的活动生命周期分为软件计划、软件开发、软件综合三大过程
数据证明目标达到的证据，即软件生命周期数据（文档、代码、报表、记录等）数据组织与配置管理要求具体

2.5 计算机网络（2.5）⭐【重点】

计算机网络是利用通信线路将地理上分散的、具有独立功能的计算机系统和通信设备按不同形式连接起来，并依靠网络软件及通信协议实现资源共享和信息传递的系统。网络技术涵盖通信技术、网络技术、组网技术和网络工程四方面。

1. 基本概念

发展四阶段 ⭐：

阶段时间特征与代表
诞生阶段20 世纪 60 年代中期之前以单个计算机为中心的远程联机系统（飞机订票系统，主机 + 2000 多终端，后出现前端机 FEP）
形成阶段60 年代中期至 70 年代多个主机互联，代表 ARPANET；IMP 转接构成通信子网，主机构成资源子网
互联互通阶段70 年代末至 90 年代开放式标准化网络，产生 TCP/IP 与 OSI 两种国际通用体系结构
高速发展阶段90 年代至今光纤与高速网络技术，发展为以 Internet 为代表的互联网

五大功能：数据通信（最主要功能之一，信息以二进制形式传递）、资源共享（硬件、软件、数据资源）、管理集中化、实现分布式处理（大课题拆分由不同计算机完成再集中）、负荷均衡（过重时自动转移负荷到较轻计算机）。

性能指标 ⭐【易错：带宽两种含义】：

指标含义要点
速率主机或通信设备在数字信道上传送数据的速率，又称数据率/比特率单位 b/s，最重要指标之一
带宽①信号具有的频带宽度（单位 Hz，如电话信号 3.1kHz）；②网络中通信线路传送数据的能力，即单位时间内结点到结点能通过的「最高数据率」网络中带宽单位是 b/s

时延数据从网络一端传送到另一端所需时间由发送时延、传播时延、处理时延、排队时延组成
往返时间 RTT从发送数据开始到收到接收方确认总共经历的时间重要性能指标
利用率信道利用率（有数据通过的概率）和网络利用率（全网信道利用率的加权平均）完全空闲的信道利用率为零

非性能指标：费用、质量、标准化、可靠性、可扩展性、可升级性、易管理性和可维护性等。

2. 通信技术 ⭐【重点】

信道分物理信道（由传输介质和设备组成，分无线和有线）和逻辑信道（发送端与接收端之间的虚拟线路，可连接或无连接，以物理信道为载体）。信息传输过程：信源 → 发信机（编码和调制）→ 信道 → 收信机（解调和译码）→ 信宿。不是所有频率的信号都能通过信道，频率响应决定哪些可以通过，可通过的频率范围大小就是信道带宽。

香农公式 ⭐【高频考点】：C = B × log₂(1 + S/N)。C 为信道容量（最大传输速率，b/s），B 为信号带宽（Hz），S/N 为信噪比（信号平均功率与噪声平均功率之比）。带宽越大、信噪比越高，信道容量越大，实际工程中需在带宽与信噪比之间权衡。

信号变换：发信机处理包括信源编码 → 信道编码 → 交织 → 脉冲成形 → 调制；收信机做相反处理（解调、采样判决、去交织、信道译码、信源译码）。

环节作用通俗理解
信源编码模拟信号模数转换 + 压缩编码去冗余，形成数字信号如 GSM 先 PCM 编码再 RPE-LPT 压缩
信道编码增加冗余信息以便接收端检错纠错只能纠正零星错误，对连续误码无能为力
交织把编码后数据顺序按规律打乱，接收端复原使连续误码变成零星误码，配合信道译码纠错
脉冲成形把发送数据转换成合适波形减小带宽需求（矩形脉冲竖边需很高频率）
调制将信息承载到满足信号要求的高频载波上便于信道传输

复用技术与多址技术 ⭐【易错】：复用技术是在一条信道上同时传输多路数据（TDM 时分复用、FDM 频分复用、CDM 码分复用，ADSL 用 FDM 使语音上下行占不同带宽）；多址技术是在一条线上同时传输多个用户的数据并在接收端分离（TDMA、FDMA、CDMA）。多路复用技术是多址技术的基础，多址还涉及信道资源分配算法（如 Walsh 码分配）。

5G 通信网络的特征技术 8 项：①基于 OFDM 优化的波形和多址接入（4G LTE/WiFi 广泛采用，可扩展大带宽、高频谱效率）；②可扩展的 OFDM 间隔参数配置（5G NR，适应丰富频谱与部署）；③OFDM 加窗提高多路传输效率（应对大规模物联网，降低带外辐射）；④灵活框架设计（STTI、自包含集成子帧）；⑤大规模 MIMO（基站端最多 256 根天线，二维排布实现 3D 波束成型）；⑥毫米波（首次将 >24GHz 频段用于移动宽带，速率高但易受阻、难穿墙）；⑦频谱共享（授权与非授权频谱利用）；⑧先进信道编码：LDPC 码（稀疏校验矩阵、性能逼近香农极限、译码可并行）和 Polar 码（信道极化，选近完美信道传输，用作 5G 控制信道的主要编码方式）。

3. 网络技术 ⭐【重点】【高频考点】

局域网（LAN）：有限地理范围内计算机互联，封闭型。五种拓扑结构 ⭐【易错：优缺点对应】：

拓扑结构特点优点缺点
星状结构每个结点都通过连接线连到中心结点，任意两结点通信最多两步传输快、结构简单、建网易、便于控制管理中心结点故障则全网瘫痪，可靠性低、共享能力差
树状结构分级的集中式网络，任意两结点间不产生回路，链路双向传输成本低、结构简单、扩充灵活、便于寻查路径除叶结点及链路外，任一工作站或链路故障都影响全网
总线结构所有结点连到一根总线上，都通过总线传输结构简单、布线少总线负载能力有限，总线故障影响每个结点
环形结构各结点首尾相连成闭合环，信息沿固定方向单向流动，两结点仅一条通路无信道选择问题、各结点地位相同任一结点故障导致物理瘫痪；不便扩充、响应延时长、效率较低
网状结构任何结点彼此之间均存在通信链路任一结点故障不影响其他结点通信，可靠性高布线烦琐、建设成本高、控制复杂

无线局域网（WLAN）：利用无线技术在空中传输数据、话音和视频，关键技术有红外传输、扩频、窄带微波等；优点是安装便捷、使用灵活、经济节约、易于扩展。标准演进：IEEE 802.11（最早，1～2Mb/s）→ 802.11b（11Mb/s）→ 802.11a（54Mb/s）→ 802.11g（与 a 同速率、兼容 b、工作在免费的 2.4GHz、更便宜）→ 802.11n（200Mb/s 以上）。三种拓扑 ⭐：

城域网（MAN）：单个城市范围内建立的计算机通信网，为整个城市而非特定部门服务；主要用光缆，速率 100Mb/s 以上，基于大型 LAN 相似技术，标准为分布式队列双总线 DQDB（IEEE 802.6）；通常分核心层、汇聚层和接入层三层（核心层高带宽承载与互联互通、汇聚层业务汇聚分发与服务等级分类、接入层多技术用户接入）。

移动通信网：1G 模拟信号（只能语音、容量有限、安全性差）→ 2G 数字调制（9.6～14.4kb/s，可传文字，移动互联网起点）→ 3G（384kb/s、室内可达 2Mb/s，大数据传送成为可能）→ 4G（体验与 20Mb/s 家庭宽带相当，进入移动互联网时代）→ 5G。5G 基本特征：高速率（峰值可大于 20Gb/s，约为 4G 的 20 倍）、低时延（从 4G 的 50ms 缩减到 1ms）、海量设备连接（1000 亿量级）、低功耗 ⭐。

4. 组网技术 ⭐【重点】【高频考点】

基本网络设备及工作层级 ⭐【易错：设备与层级配对】：

设备工作层级核心功能
集线器物理层（最简单设备）一个端口收到的数据转送到所有其他端口，含上联端口
中继器物理层接收识别并再生信号后发送到其他分支，可连接不同物理介质，要求各分支数据包和逻辑链路协议相同
网桥数据链路层含中继器功能，可连多种介质与不同物理分支（以太网、令牌网），上层信息对其透明
交换机数据链路层为任意两结点提供独享转发通路，从端口接收数据经内部处理转发到指定端口；自动寻址、避免端口冲突、提高吞吐
路由器网络层在多个网络上交换和路由数据包，经路由信息生成路由表进行路径选择，常用于广域网或广域网与局域网互连
防火墙网络门户（规则过滤）设安全规则对进出网络数据监视和过滤；硬件防火墙把程序做到芯片里，减轻 CPU 负担、路由更稳定

OSI/RM 七层参考模型：ISO 公布的开放系统互连参考模型，由低层至高层为物理层、数据链路层、网络层、传输层、会话层、表示层、应用层 ⭐【必背】。分层思想：每一层在下层服务基础上提供更高级增值服务，最高层提供运行分布式应用程序的服务，通过分层分解复杂问题、保持层间独立。

助记：七层从下到上——「物、数、网、传、会、表、应」（物理、数据链路、网络、传输、会话、表示、应用）。

TCP/IP 协议集：Internet 核心协议，特性为逻辑编址、路由选择、域名解析、错误检测和流量控制及应用支持；是个协议族，主要包括 IP、TCP、UDP、TELNET、FTP、SMTP、NNTP、HTTP 等 8 个。模型分网络接口层、网际层、传输层、应用层 4 层：网络接口层未详细描述（主机用某种协议与网络相连）；网际层是关键部分，使主机把分组发往任何网络并独立传向目标；传输层定义两个端到端协议 TCP 和 UDP。

OSI 与 TCP/IP 对照 ⭐【高频考点】：

OSI 七层TCP/IP 四层对应主要协议
应用层、表示层、会话层应用层FTP（文件传输）、Telnet（远程登录）、SMTP（电子邮件）、NFS（网络文件服务）、SNMP（网络管理）、HTTP 等
传输层传输层TCP、UDP
网络层网际层IP、ICMP、ARP、RARP
数据链路层、物理层网络接口层Ethernet/IEEE 802.3、FDDI、Token-Ring、ARCnet、PPP/SLIP 等

Internet 地址有域名格式和 IP 地址格式两种表示，域名与 IP 地址一一对应；IP 协议版本 4 为 IPv4、版本 6 为 IPv6。WWW 万维网采用统一资源定位器 URL；常用服务有 DNS、WWW、E-mail、FTP、Telnet 等。

交换技术：交换机功能包括集线功能、中继功能（转发帧时重新产生不失真电信号）、桥接功能、隔离冲突域功能（每个冲突域有独立带宽）。基本交换原理 ⭐：

功能原理
转发路径学习根据收到帧的源 MAC 地址建立该地址与端口的映射，写入 MAC 地址表
数据转发目的 MAC 在表中查到，则向对应端口转发
数据泛洪目的 MAC 不在表中，则向所有端口转发（泛洪）；广播帧和组播帧向所有端口（不包括源端口）转发
链路地址更新MAC 地址表每隔一定时间（如 300s）更新一次

交换机组网中多条物理链路会形成环路，导致数据转发异常，生成树协议（STP）可解决链路环路问题 ⭐；为提高链路可靠性或提升端口带宽，可采用链路聚合协议（如 802.3ad）。

路由技术：路由器功能包括异种网络互连、子网协议转换、数据路由、速率适配、隔离网络防广播风暴（防火墙）、报文分片和重组（超 MTU 分片、到目的地重组）、备份与流量控制。路由原理：工作在网络层，根据数据包目的地址查路由表决定下一跳地址；路由表可静态配置，也可由动态路由协议自动生成。路由协议是运行在路由器上、让路由器自动学习其他路由器网络并在拓扑变化后自动更新路由表的协议，分两类 ⭐：

类别范围细分与代表

5. 网络工程

网络建设分三环节：网络规划（首要环节：需求分析、可行性分析、现有网络分析，以需求为导向兼顾技术与工程可行性）、网络设计（总体目标与原则、通信子网设计、设备选型、网络安全设计）、网络实施（工程实施计划、设备验收、安装调试、系统试运行和切换、用户培训）。

2.6 计算机语言（2.6）⭐【重点】

计算机语言是人与计算机之间传递信息的媒介，主要由一套指令组成，包括表达式（变量、常量、字面量和运算符）、流程控制（分支、循环、函数和异常）和集合（字符串、数组、散列表等数据结构）三大部分。早期分为机器语言、汇编语言和高级语言三大类，本章再增建模语言与形式化语言。

1. 机器语言

机器语言是第一代计算机语言，全部指令的集合称指令系统，可被计算机直接理解和执行，优点是执行速度快、占用内存少；缺点是 0/1 串编程烦琐、难学难记难调试，且依赖机器硬件、不可移植。

指令格式：指令是二进制代码，一条指令包括操作码和地址码两种信息 ⭐。完整指令需指出：操作码（操作性质功能）、操作数的地址、操作结果的存储地址、下条指令的地址。用程序计数器 PC 存放下条指令地址：每执行一条指令 PC 自动 +1，遇转移指令时用转移地址修改 PC，因此指令中不必显式给出下条指令地址。操作码长度取决于指令系统中的指令条数；地址码描述操作对象（直接给操作数，或指出存储器/寄存器地址）。

常见指令格式按地址域数量分 ⭐：

格式地址安排备注
三地址指令A1、A2 为两个操作数地址，A3 为结果地址下条指令地址由 PC 顺序给出
二地址指令A1 为第 1 操作数地址，A2 同时确定第 2 操作数地址和结果地址结果覆盖第 2 操作数
单地址指令A 为第 1 操作数地址第 2 操作数与结果固定使用某个寄存器（地址隐含）
零地址指令堆栈型计算机中操作数在栈顶两单元、结果放回栈顶地址均隐含，只有操作码
可变地址数指令地址数随操作定义改变可少至 0 个、多至 6 个

2. 汇编语言

汇编语言是第二代计算机语言，是机器语言的符号化描述（如 ADD 表加法、MOV 表数据传送），代码短、省空间、效率高，但仍是面向机器的语言，通用性差、可移植性不好；把符号翻译成二进制机器语言的程序称汇编程序。

源程序中有 3 种语句 ⭐【易错：是否产生机器代码】：

语句作用是否产生机器代码
指令语句（机器指令语句）汇编后被 CPU 直接识别执行（ADD、SUB、AND 等）产生（操作在程序运行时完成）
伪指令语句指示汇编程序在汇编时完成某些工作（分配存储单元、符号赋值）不产生（操作在汇编时完成）
宏指令语句把多次重复使用的程序段定义为宏，在需要处用宏名引用宏的引用，展开后按指令处理

指令语句和伪指令语句格式相同，均由名字、操作符、操作数和注释4 个字段组成：指令语句的名字叫标号、必须以冒号结束（代表指令第 1 个字节的符号地址），伪指令语句名字后用空格结束、不得用冒号（重要区别）；操作符字段不可缺少（指令助记符或 DB/DW/DD、SEGMENT、PROC 等伪指令）；操作数可有多个、用逗号或空格分隔；注释字段任选、以分号开始、不进目标程序。

3. 高级语言

高级语言是一类语言的统称，比汇编语言更贴近人类语言，与计算机架构、指令集无关，可移植性好。代表：

4. 建模语言（UML）⭐【高频考点】

面向对象建模语言在 20 世纪 90 年代多达 50 余种，阻碍交流，联合设计小组求同存异推出 UML（Booch、OMT、OOSE 融合）。1997 年 10 月 OMG 采纳 UML 1.1 作为标准建模语言，1999 年底占面向对象建模市场 90%，成为事实上的工业标准。UML 是定义良好、易于表达、功能强大且普遍适用的建模语言，支持从需求分析开始的软件开发全过程；它与程序设计语言无关，只是语言而不是方法学 ⭐【易错：UML 不是开发方法】。

UML 由 3 个要素构成：基本构造块（事物、关系）、图（支配构造块如何放置的规则）和公用机制。其中：

事物 4 种：结构事物（模型的名词、静态部分：类、接口、协作、用例、主动类、构件、制品、结点）；行为事物（模型的动词、动态部分：交互、状态机、活动）；分组事物（组织部分，主要是包，仅在开发时存在，与仅运行时存在的构件不同）；注释事物（解释部分，主要是注解）。

5. 形式化语言

形式化方法是用具有精确语义的形式语言书写程序功能描述，把概念、判断、推理转化成形式符号研究，是设计编制程序的出发点、验证程序是否正确的依据，能确保与需求一致并用于分析验证。

规格说明语言主要流派：①公理方法（前置条件与后置条件描述程序行为，代表 Floyd、Hoare、Dijkstra）；②基于集合论和一阶谓词演算的 meta-IV 和 Z 语言（meta-IV 对应维也纳开发方法 VDM）；③代数规格说明（抽象数据类型的代数描述，OBJ、ACT）；④进程描述语言（描述开发进程行为，Hoare 的 CSP、Milner 的 CCS）。ISO 认可的规格说明语言有 LOTOS、ESTELLE、SDL、Z.100 等。

形式化方法分类：按系统特性分面向对象（Z、VDM、B、Object-Z）、面向属性（OBJ3、Larch）、基于并发性（CCS、ACP、CSP、LOTOS）、基于实时性（TRIO、RTOZ）；按描述方式分模型描述（构造数学模型直接描述）与性质描述（描述系统性质间接描述）；按表达能力分模型方法（显式描述状态与动作，不能显式表示并发）、代数方法（隐式描述操作，也不能显式表示并发）、进程代数方法（显式模型描述并发，交错语义）、逻辑方法（逻辑描述程序/时间状态规范）、网络模型方法（如 Petri 网，独立描述每个结点、显式给出并发模型）。

形式化开发过程：贯穿可行性分析、需求分析、体系结构设计、详细设计、编码、测试发布 6 阶段——需求阶段要求明确描述需求；体系结构设计可采用半形式化方法；编码阶段自动代码生成器可把较小系统的形式化描述直接转为可执行程序；测试阶段可用于测试用例自动生成、保证覆盖率。

Z 语言 ⭐【易错】：具有「状态—操作」风格的形式化规格说明语言，以一阶逻辑和集合论为形式语义基础，最主要的结构是模式（Schema），一个模式由变量说明和谓词约束两部分组成，描述系统状态和操作；是强类型系统（每个对象有唯一类型）；可结合自然语言书写；支持求精（从抽象模型逐步精化到可执行代码）；优点是精确、简洁、无二义性，适用于无法现场调试的高安全性系统。Z 语言没有提供计时或并发行为的描述，可与 CSP、CCS 等结合产生含并发行为的规格说明。

2.8 系统工程（2.8）⭐【重点】

1. 基本概念

系统工程是一种组织管理技术：把研究对象看作由很多相互联系、相互制约的组成部分构成的总体，运用运筹学理论方法及电子计算机技术，对各组成部分进行分析、预测和评价，最后综合使系统达到最优。产生于第二次世界大战期间，1960 年美国阿波罗登月计划成功运用系统工程，此后获迅速发展。

系统（ISO/IEC 15288:2008）是人造的、被创建用于在定义明确的环境中提供产品或服务的组合，系统元素包括硬件、软件、数据、人员、流程、设施、材料等；系统是由交互的元素组织起来的组合，用以实现一个或多个特定目的。系统之系统（SoS）指系统元素本身也是系统的情况（如 GPS 既是飞机机载导航系统的组成，也是汽车导航系统的组成），部件系统互操作能产生单个系统无法单独达成的结果。

钱学森（1978）：系统工程是组织管理「系统」的规划、研究、设计、制造、试验和使用的科学方法，是一种对所有「系统」都具有普遍意义的科学方法。INCOSE：系统工程是一种使系统能够成功实现的跨学科的方法和手段，专注开发周期早期定义客户需求与功能并文件化，再考虑运行、成本、进度、性能、培训、保障、制造和退出等完整问题。核心特征：跨学科、技术和整体性（系统思维）——分析和设计与其部分截然不同的整体，全面看问题并把社会方面与技术方面联系起来。

2. 系统工程方法 ⭐【高频考点】

系统工程方法的特点是整体性、综合性、协调性、科学性和实践性，包括整体观念、综合观念、科学观念和创新观念。

① 霍尔三维结构（硬系统方法论 HSM）：美国系统工程专家霍尔（A.D.Hall）1969 年提出，将系统工程活动分为前后衔接的 7 个时间阶段和 7 个逻辑步骤，加上所需专业知识技能，形成时间维、逻辑维、知识维三维结构 ⭐【必背】：

维度内容
时间维规划、拟订方案、研制、生产、安装、运行、更新 7 个时间阶段
逻辑维明确问题、确定目标、系统综合、系统分析、优化、决策、实施 7 个逻辑步骤
知识维工程、医学、建筑、商业、法律、管理、社会科学、艺术等各种专业知识和技能

霍尔三维结构集中体现系统工程方法的系统化、综合化、最优化、程序化和标准化特点，为解决大型复杂系统的规划、组织、管理提供统一思想方法。

霍尔三维结构

② 切克兰德方法（软系统方法论）：英国 P.切克兰德 20 世纪 80 年代中前期提出。社会经济系统的问题难以事先确定需求、难以定量分析，核心不是「最优化」而是「比较」与「探寻」——从模型和现状的比较中学习改善现状的途径，含有组织讨论、听取各方意见的意思，更好反映人的因素。工作过程 7 步：认识问题 → 根底定义 → 建立概念模型 → 比较及探寻 → 选择 → 设计与实施 → 评估与反馈。

③ 并行工程（Concurrent Engineering）：对产品及其相关过程（制造和支持过程）进行并行、集成化处理的系统方法，要求设计开始即考虑产品生命周期全过程（质量、成本、用户要求及工艺与服务质量）。目标是提高质量、降低成本、缩短产品开发周期和上市时间；做法是产品开发初期组织多职能协同项目组，使问题在开发早期解决、避免返工；强调设计开发期间结合概念/结构/工艺设计与最终需求、项目小组随时或定期反馈协调、依据信息系统工具（如 CIM）辅助并行化。

④ 综合集成法：钱学森等 1990 年初提出「从定性到定量的综合集成法」，用于处理开放的复杂巨系统（子系统种类很多且有层次结构、关联复杂且开放），区别于培根式还原论。系统分类：简单系统 → 巨系统（子系统成千上万）→ 简单巨系统（种类不多、关联简单，如激光系统）→ 开放的复杂巨系统。开放复杂巨系统性质：开放性、复杂性、进化与涌现性、层次性、巨量性。1992 年钱学森又提出综合集成研讨厅体系：将专家群体、数据和各种信息与计算机网络有机结合。主要特点：定性与定量结合贯穿全过程、科学理论与经验知识结合、多学科综合、宏观与微观统一、必须有大型计算机系统支持。

⑤ WSR 系统方法：物理（Wuli）- 事理（Shili）- 人理（Renli）方法论，顾基发教授和朱志昌博士 1994 年在英国 HULL 大学提出，属定性与定量综合集成的东方系统思想。实践准则是「懂物理、明事理、通人理」。一般工作过程 7 步：理解意图、制定目标、调查分析、构造策略、选择方案、协调关系、实现构想；协调关系始终贯穿整个过程（协调每一步物理事理人理、意图目标现实策略方案构想、投入产出成效的关系）。物理主要用自然科学方法，事理主要用运筹学、系统工程、管理科学、控制论及软计算、特尔斐法、层次分析法等，人理可细分为关系、感情、习惯、知识、利益、和解与管理等。

2. 性能计算

主要方法有定义法、公式法、程序检测法和仪器检测法；常用计算过程有 MIPS（每秒百万条指令）计算、峰值计算、等效指令速度（吉普森 Gibson 法）；实际应用中常对指标复合计算并加权处理得最终结果。

3. 性能设计

性能调整：系统性能降到基本水平时由查找和消除瓶颈组成。数据库系统关注 CPU/内存使用、数据库设计与管理优化、进程线程状态、硬盘剩余空间、日志文件大小；应用系统关注可用性、响应时间、并发用户数与资源占用。开始前必须识别约束、指定负载、设置性能目标；调整是重复受控的试验，循环过程为收集、分析、配置和测试。

阿姆达尔（Amdahl）定律 ⭐【高频考点】：对某一部件采用更快执行方式所获得的系统性能改变程度，取决于这种方式被使用的频率或所占总执行时间的比例。

加速比 = 不使用增强部件时完成整个任务的时间 / 使用增强部件时完成整个任务的时间，它取决于两个因素：增强比例（能被改进增强的部分在总执行时间中所占比例，≤1）和增强加速比（增强部分本身速度提高的倍数）。公式：

新的执行时间 = 原来的执行时间 × [(1 − 增强比例) + 增强比例 / 增强加速比]

总加速比 = 1 / [(1 − 增强比例) + 增强比例 / 增强加速比]

举例：某功能部件占总执行时间的 60%，采用增强部件后该部分速度提高到原来的 10 倍，则总加速比 = 1 / [(1 − 0.6) + 0.6/10] = 1 / (0.4 + 0.06) = 1/0.46 ≈ 2.17。可见局部提升再大，整体加速也受未改进部分（40%）限制——这就是「加速比取决于改进部分所占比例」的含义，也是性能优化要先找主要瓶颈的原因。

4. 性能评估

性能评估是为了一个目的，按照一定步骤，选用一定度量项目，通过建模和实验，对系统性能进行各项检测、解释测试结果并形成文档的技术，目的之一是为性能优化提供参考。

基准测试程序：把应用程序中用得最多、最频繁的核心程序作为评价计算机性能的标准程序（benchmark）。4 种评价程序评测准确程度依次递减 ⭐【易错：顺序】：真实的程序 > 核心程序 > 小型基准程序 > 合成基准程序。常用基准测试程序有整数测试 Dhrystone、浮点测试 Linpack、Whetstone、SPEC 和 TPC 基准程序。

Web 服务器性能评估：指标为最大并发连接数、响应延迟和吞吐量；常见评测方法有基准性能测试、压力测试和可靠性测试。

系统监视 3 种方式：①系统本身提供的命令（UNIX/Linux 的 w、ps、last，Windows 的 netstat 等）；②通过系统记录文件查阅特定时间运行状态；③集成命令、文件记录和可视化技术（如 Windows 的 Perfmon）。

1. C。CISC 以 x86 为代表，RISC 以 ARM/Power 为代表且是发展趋势。
