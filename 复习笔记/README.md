# 系统架构设计师（第二版）复习笔记

按教材《系统架构设计师第二版》章节组织的复习目录，共 20 章，与教材上篇（第 1～11 章）、下篇（第 12～20 章）对应。

## 使用方法

1. 每章一个目录，目录下的 `README.md` 为该章复习笔记模板。
2. 复习时依次填写：大纲考点 → 知识点笔记 → 重点与易错点 → 练习与真题 → 疑问与查漏补缺。
3. 完成一章后，将本章状态改为「已完成」，并更新下方总表。
4. 页码为教材 PDF 的文件页码（非书页页码），便于快速跳转。
